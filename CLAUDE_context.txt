**Project: Calgary Water Main GIS Dashboard**

A web-based GIS dashboard exploring water main incidents in Calgary. Tech stack: FastAPI (Python) backend, MapLibre + React/TypeScript frontend, PostGIS database running in a Podman pod.

**Infrastructure (complete):**
- Podman pod named `postgis` running two containers: `docker.io/postgis/postgis` (named `postgres`) and `docker.io/dpage/pgadmin4` (named `pgadmin`)
- Pod exposes PostGIS on `localhost:5433` (external) / `5432` (internal), pgAdmin on `localhost:8088`
- Credentials stored in `.env`, excluded from git via `.gitignore`
- Setup script at `backend/setup.sh`, persistent data in `./poddata/`
- WSL2 on Windows — all Podman commands run inside WSL2 terminal
- Python package manager is `uv`, Node manager is `fnm`

**Weather data (in progress):**
- Using Environment Canada's API (`https://api.weather.gc.ca`)
- Identified one relevant weather station: **CALGARY INT'L CS**, `CLIMATE_IDENTIFIER: 3031094`, 8.42 km from Calgary Tower
- Station has daily data from 1999-05-01 and hourly data from 2008-12-22, both current to May 2026
- Station metadata saved to `backend/weather_stations.json`
- Script that found this station is at `backend/explore_stations.py`

**Next task: weather data ingestion**

Three scripts to write, all in `backend/`:
1. `ingest_historical.py` — one-time backfill of daily data from 2000-01-01 to today
2. `update_daily.py` — runs once per day, fetches and upserts yesterday's daily reading
3. `update_hourly.py` — runs every hour, fetches latest hourly reading, inserts it, prunes old records (no large archive needed)

**Proposed database tables:**
- `weather_station` — station metadata from `weather_stations.json`
- `climate_daily_raw` — raw daily observations per station
- `climate_hourly_raw` — raw hourly observations, rolling window only
- `climate_daily_agg` and `climate_hourly_agg` — aggregated tables in case multiple stations are added later
